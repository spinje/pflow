## Context

The cache analyzer (`src/pflow/core/cache_analysis/`) ships feature-complete on this branch. Five clusters of post-merge polish have already landed (Cluster A through E). Two real research handoffs identified four remaining defects in the analyzer's per-call section and recommendation surface:

1. `partial-declaration-detection-handoff.md` — workflow declares `## Cache`, a node has `prompt_cache: [a]` but its prompt also references `${b}` shared with another node. Analyzer emits zero diagnostics.
2. `select-chorus-and-tier2-scope-gap-handoff.md` — Tier 2 chunk-path returns per-call tokens while `input_tokens_estimated` is cohort-summed (for some row classes). Per-call rows show contradictory units.

Plan v1.0 was reviewed by 5 specialized agents. They surfaced:
- **A design issue**: producer-side multiplication of Tier 2 cacheable created asymmetric semantics with the planned input divisor, silently breaking the clamp at `analyze.py:1548`, the `cache.below-min-tokens` detector, and the summary aggregator.
- **A reuse opportunity** flagged by two reviewers independently: Pass B's prompt-body cleanup logic should call existing `cache_overlap.compute_overlaps()` (or its wrapper `_compute_prompt_body_cleanup` at `analyze.py:2934-2969`) instead of reinventing it. Eliminates body-shadow leakage and batch-alias filter need by construction.
- **A scope gap**: Pass A.A2 must divide both input AND output AND Tier 1 cacheable for static-list batch rows; output cost is 60-85% of total per CLAUDE.md, dividing only input is a partial fix.
- **A latent bug**: `cache.below-min-tokens` predicted-tier reads `row.cacheable_tokens_estimated` directly. Threshold is per-call by provider rule; if cacheable is cohort, threshold check is units-mismatched.

The intended outcome:

- A workflow with `## Cache` declared and shared refs not in some nodes' `prompt_cache:` lists emits one diagnostic per affected workflow, with corrected list and prompt-body cleanup hint generated by the SAME helper the validator uses.
- Cost projections for static-list batch trace rows are no longer inflated by factor `N` (currently affecting input, output, and cache-read costs equally).
- Per-call cacheable column matches input column units (both per-call) for batch rows; non-batch repeated rows continue to show cosmetically mismatched units (deferred under Heuristic A).
- The contradictory `Per-call cache report hidden` note no longer renders on workflows whose rows have parameter-backed cacheable evidence.

### B1. Detector function — REUSE existing primitives

**Critical reviewer convergence (validation-consistency C1+C2, plan-review C2+C3+C4, impact-completeness W1)**: do NOT reinvent template scanning or overlap detection. The codebase already has the right primitives.

Reuse:

- `TemplateResolver.split_coalesce_operands` — splits coalesce operands properly.
- `_template_root_segment` (`analyze.py:2390-2404`) — `ref.split(".", 1)[0].split("[", 1)[0]`. Handles dotted vars and bracket access.

- `cache_overlap.compute_overlaps()` — canonical overlap detector. Returns 3 overlap kinds: `duplicate`, `cache_contains_body`, `body_contains_cache`. Both validation-consistency and plan-review reviewers recommended calling this directly to derive cleanup hints.
- `_compute_prompt_body_cleanup` (`analyze.py:2934-2969`) — already implements "given a node and its corrected prompt_cache, what cleanup is needed?" using `compute_overlaps`. Likely reusable as-is or with minor signature adjustment.

**`_longest_var_prefix_match` helper**:

```python
def _longest_var_prefix_match(operand: str, vars_: Iterable[str]) -> str | None:
    """Returns the longest var v such that operand == v OR operand.startswith(f"{v}.") OR operand.startswith(f"{v}[").

    Longest-match disambiguates dotted vars: a cache item with var
    "creative-direction.response" beats a cache item with var
    "creative-direction" when the operand is "creative-direction.response.x".

    Returns None if operand matches no var (caller skips it).
    """
    if not operand:  # defensive: empty operand from malformed ${} -> no match
        return None
    best: str | None = None
    for v in vars_:
        if not isinstance(v, str) or not v:
            continue  # defensive: malformed cache item with non-string var
        if operand == v or operand.startswith(f"{v}.") or operand.startswith(f"{v}["):
            if best is None or len(v) > len(best):
                best = v
    return best
```

**Algorithm**:

```python
def _detect_partial_prompt_cache_declarations(
    workflow_ir: dict[str, Any],
    workflow_path: str | None,
    ctx: AnalysisContext,
) -> list[_PartialDeclarationFinding]:
    # Gate 1: Workflow must declare ## Cache.
    if not _cache_item_names(workflow_ir):
        return []

    # Build cache item index. Defensive against malformed items.
    items = [
        item for item in workflow_ir.get("cache", {}).get("items", [])
        if isinstance(item, dict) and "name" in item
    ]
    if not items:
        return []

    name_order = [item["name"] for item in items]
    var_to_name: dict[str, str] = {}
    for item in items:
        # Parser locks name == var, but direct-IR can diverge. Test fixture #4
        # exercises this. Filter non-string vars defensively.
        var = item.get("var", item["name"])
        if isinstance(var, str) and var:
            var_to_name[var] = item["name"]

    # Bucket refs by cache item name (root-aware, batch-alias filtered).
    refs_by_name = _collect_llm_template_root_references(workflow_ir, var_to_name)

    findings: list[_PartialDeclarationFinding] = []
    for node in workflow_ir.get("nodes", []):
        if node.get("type") != "llm":
            continue
        node_id = node.get("id")
        declared_raw = node.get("prompt_cache")
        if not isinstance(declared_raw, list):
            continue  # validator handles malformed
        declared = tuple(str(c) for c in declared_raw)

        # Which cache items does THIS node's prompt reference (root-aware)?
        prompt = node.get("params", {}).get("prompt", "")
        if not isinstance(prompt, str):
            continue
        node_refs = set()
        for operand in TemplateResolver.TEMPLATE_PATTERN.findall(prompt):
            for sub_operand in TemplateResolver.split_coalesce_operands(operand):
                if _is_batch_scoped_ref(sub_operand, _batch_aliases(node)):
                    continue
                matched_var = _longest_var_prefix_match(sub_operand, var_to_name.keys())
                if matched_var is not None:
                    node_refs.add(var_to_name[matched_var])

        # Missing = referenced ∩ shared(≥2 nodes) ∩ NOT declared
        missing = []
        for name in name_order:  # preserve declaration order
            if name not in node_refs:
                continue
            if name in declared:
                continue
            consumers = set(refs_by_name.get(name, []))
            if len(consumers) < 2:
                continue  # not shared; lower-priority and out of scope
            missing.append(name)

        if not missing:
            continue

        # Corrected list, declaration-order-safe (validator-friendly).
        corrected = tuple(
            name for name in name_order
            if name in set(declared) | set(missing)
        )

        # REUSE: cleanup hint via the canonical overlap detector.
        # _compute_prompt_body_cleanup(node, corrected_prompt_cache, items)
        # already implements this exactly via cache_overlap.compute_overlaps.
        # Verify exact signature when implementing; adapt if needed.
        cleanup = _compute_prompt_body_cleanup(node, corrected, items)

        # Per-node threshold tokens via _estimate_ref_tokens (per-call).
        # Reviewer plan-review W5 + impact-completeness S2: threshold is
        # about CACHEABLE content (missing chunks), not the whole prompt.
        missing_chunks_tokens = _estimate_missing_chunks_tokens(
            missing, var_to_name, ctx, workflow_path,
        )

        # Representative model for threshold check (first non-empty model
        # from rows; mirrors _consolidate_to_root_advisories pattern).
        rep_model = _representative_model_for_node(node_id, ctx, workflow_path)

        findings.append(_PartialDeclarationFinding(
            node_id=node_id,
            declared_chunks=declared,
            missing_chunks=tuple(missing),
            corrected_prompt_cache=corrected,
            prompt_body_cleanup=cleanup,
            missing_chunks_tokens=missing_chunks_tokens,
            rep_model=rep_model,
        ))

    return findings
```

**Helper `_estimate_missing_chunks_tokens`**:

```python
def _estimate_missing_chunks_tokens(
    missing_names: list[str],
    var_to_name: dict[str, str],
    ctx: AnalysisContext,
    workflow_path: str | None,
) -> int | None:
    """Sum per-call token estimates for the missing cache items' values.

    Mirrors _sum_resolved_chunk_tokens but operates on cache item NAMES
    (resolves to their var via reverse map). Returns None when any chunk
    is unresolvable (honest unmeasurable).
    """
    name_to_var = {name: var for var, name in var_to_name.items()}
    total = 0
    for name in missing_names:
        var = name_to_var.get(name)
        if var is None:
            return None  # malformed cache item slipped through
        tokens = _estimate_ref_tokens(
            var, model=...,  # picked from rep_model or skipped
            memo_cache=ctx.memo_cache, workflow_path=workflow_path, ctx=ctx,
        )
        if tokens is None:
            return None
        total += tokens
    return total
```

**Edge cases handled** (consolidates reviewer findings):
- Workflow has no `## Cache` items → returns `[]`.
- Workflow has cache items but no LLM nodes with `prompt_cache:` → returns `[]`.
- Cache item with `var` containing dots (`creative-direction.response`) → `_longest_var_prefix_match` longest-match wins.
- Cache item missing `name` and/or `var` → defensive filter at index-build.
- Batch-scoped refs → filtered via `_is_batch_scoped_ref`.
- External `.prompt.md` files → inlined by `file_resolver` before analyzer time (verifier #1 confirmed Path 1 boundary).
- Direct-IR with `name != var` → `var_to_name` map handles correctly. Test #4 locks.
- `name == var` parser invariant → noted in test #4 docstring (cannot occur in `.pflow.md` source; only direct-IR).
- Only ONE node references the cache item → not "shared"; skip.
- Node already declares all referenced shared chunks → no missing; skip.
- LLM node prompt is None / non-string → skip.
- Cleanup hint via `_compute_prompt_body_cleanup` handles all 3 overlap kinds (duplicate, cache_contains_body, body_contains_cache). Eliminates body-shadow leakage.

```python
def _emit_partial_declaration_findings(
    cw_result: CrossWorkflowResult,
    rows_by_node_path: dict[tuple[str, str], PerCallRow],
    ctx: AnalysisContext,
    consolidate_root_diags: list[Diagnostic],  # for C3 precedence
) -> list[Diagnostic]:
    diagnostics = []
    consolidate_roots = _extract_consolidate_roots(consolidate_root_diags)

    for workflow_path, workflow_ir in cw_result.irs_by_workflow.items():
        findings = _detect_partial_prompt_cache_declarations(
            workflow_ir, workflow_path, ctx,
        )
        if not findings:
            continue

        # Per reviewer C3: suppress findings whose missing chunks overlap with
        # an existing cache.consolidate-to-root-recommended root for the same
        # workflow. Those agents are guided to consolidate first; partial-
        # declaration would then resolve.
        findings = [
            f for f in findings
            if not _findings_chunks_overlap_with_consolidate(
                f.missing_chunks, consolidate_roots, workflow_path,
            )
        ]
        if not findings:
            continue

        # Per-node threshold check (reviewer C5 heterogeneous-models fix):
        # If ANY affected node's missing chunks fall below its model's
        # min-cache-tokens, force savings_usd=None and add per-model footnote.
        any_below_threshold = any(
            _is_below_min_cache_tokens(f.missing_chunks_tokens, f.rep_model)
            for f in findings
        )
        below_threshold_clause = (
            _below_threshold_clause_for_findings(findings) if any_below_threshold else ""
        )
        savings_usd: float | None = None
        if not any_below_threshold:
            savings_usd = _project_partial_declaration_savings(findings, ctx)

        # Build context payload.
        node_findings_dicts = [
            {
                "node_id": f.node_id,
                "missing_chunks": list(f.missing_chunks),
                "missing_chunks_csv": ", ".join(f"`{c}`" for c in f.missing_chunks),
                "corrected_prompt_cache": list(f.corrected_prompt_cache),
                "corrected_prompt_cache_inline": "[" + ", ".join(f.corrected_prompt_cache) + "]",
                "prompt_body_cleanup": list(f.prompt_body_cleanup),
                "prompt_body_cleanup_csv": ", ".join(f.prompt_body_cleanup) or "(none)",
                "rep_model": f.rep_model,
                "missing_chunks_tokens": f.missing_chunks_tokens,
            }
            for f in findings
        ]
        node_findings_block = _format_node_findings_block(findings)
        workflow_basename = (
            os.path.basename(workflow_path) if workflow_path else "<inline>"
        )

        diagnostics.append(make_diagnostic(
            "cache.prompt-cache-incomplete",
            node_id=None,  # workflow-level (matches established convention)
            affected_workflow=workflow_path or "<inline>",
            workflow_basename=workflow_basename,
            affected_node_count=len(findings),
            node_findings=node_findings_dicts,
            node_findings_block=node_findings_block,
            below_threshold_clause=below_threshold_clause,
            savings_usd=savings_usd,
        ))
    return diagnostics
```
