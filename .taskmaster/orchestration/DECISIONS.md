# DECISIONS.md — settled programme & process decisions

Numbered ledger of decisions below the ADR bar (process, routing, authority — not product
architecture; that's `context/adr/`). **Rows are not re-litigated**: new information that
contradicts one is a user escalation, and when a decision changes the row is updated in the same
breath. ADR-bar decisions get an ADR AND a row pointing at it. Write side: the main orchestrator.
